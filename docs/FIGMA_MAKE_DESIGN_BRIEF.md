## 0) دستور کار برای Make (اول این را بخوان)

1. **فقط روی برنچ `design` کار کن.** روی `main` کامیت/پوش نکن مگر صریح گفته شود.
2. هدف این بریف **بازطراحی UX/UI** است؛ منطق کسب‌وکار و داده را عوض نکن مگر برای پشتیبانی از layout بهتر.
3. ظاهر باید **مطابق برند و دیزاین‌سیستم اسمارت (SmartX)** باشد — نه تم آبی/بنفش عمومی AI، نه داشبورد شلوغ SaaS.
4. اولویت اول: **جایگاه کامپوننت‌ها و مسیر بررسی** بهتر شود. هویت بصری بخش‌ها الان نسبتاً خوب است؛ آن را حفظ و صیقل بده.
5. خروجی مطلوب در Figma:
   - فریم‌های RTL دسکتاپ (+ در صورت امکان موبایل برای شِل و مسیر بررسی)
   - صفحات کلیدی journey
   - پیشنهاد layout جایگزین برای مسیر بررسی (حداقل ۲ گزینهٔ ترکیب/جریان)
6. زبان UI: **فارسی RTL**. اعداد در UI ترجیحاً فارسی (IRANYekan FaNum).

## 1) محصول چیست؟

دیدبان ابزاری داخلی برای تیم کنترل کیفیت اسمارت است تا:

1. نوع بررسی را انتخاب کنند (سریع / پس از تحویل / تماس بعد تمدید / …)
2. مجموعه (برند/شعبه) و بازهٔ شمسی را بگذارند
3. گزارش زنده از شاخص‌ها ببینند (رضایت، اشتراک، شارژ، اتصال، …)
4. نکات پیگیری را چک کنند
5. PDF / پیام مشتری بفرستند
6. صندوق گزارش‌ها و صندوق پیشنهادات (باگ/بهبود) را مدیریت کنند

کاربر اصلی: اپراتور مانیتورینگ + ادمین/سوپرادمین.

## 4) تمرکز اصلی این درخواست (Must improve)

### ۴.۱ جایگاه کامپوننت‌ها (بالاترین اولویت)

الان خیلی از صفحات «درست کار می‌کنند» ولی چیدمان می‌تواند واضح‌تر باشد:

- **خانه:** کارت‌های نوع بررسی — سلسله‌مراتب عنوان/توضیح/تعداد بخش؛ فاصله و اسکن سریع‌تر
- **Setup:** سه استپ (مجموعه → بازه → محتوا) — تقویم شمسی نباید بریده شود؛ BrandSearch باید زیر فیلد بنشیند نه در هوا
- **گزارش:** متریک‌ها، hints، اسکور، مرحله‌ها — کمتر تو در تو، کمتر تکرار برچسب
- **Admin کیفی شاخص‌ها:** کارت متریک + «وضعیت پیشرفته» — پیشرفته جمع‌وجور و ثانویه بماند
- **Feedback:** لیست شبیه inbox تمیز؛ جزئیات با گفتگو/عکس بدون شلوغی

از Make بخواه:

1. برای هر صفحهٔ کلیدی یک **wireframe چیدمان** (جایگاه بلوک‌ها)
2. سپس یک **visual polish** هم‌رنگ برند
3. مشخص کن چه چیزی حذف/ادغام/جابه‌جا شده و چرا

### ۴.۲ مسیر بررسی (Journey) بهتر شود

مسیر فعلی:

```
خانه → انتخاب نوع بررسی → Setup (برند/بازه/بخش‌ها) → گزارش
گزارش: خلاصه → بخش‌به‌بخش → نکات پیگیری → ارسال/PDF
```

دردهای محتمل برای بازطراحی:

- جهش ذهنی زیاد بین Setup و Report
- مرحله‌های افقی گزارش ممکن است کم‌وضوح باشند
- کاربر نمی‌فهمد «الان کجای مسیر است» و «قدم بعدی چیست»
- انتخاب بازهٔ دلخواه / برند گاهی اصطکاک UI دارد

از Make بخواه حداقل **۲ پیشنهاد جریان**:

| گزینه | ایده |
|-------|------|
| A | بهبود همان ۳ استپ Setup + chips گزارش (کم‌ریسک) |
| B | یک wizard یکپارچه‌تر (برند → بازه → پیش‌نمایش خلاصه → عمیق شدن در بخش‌ها) |

معیار موفقیت جریان:

- در ۳ ثانیه معلوم باشد مرحلهٔ فعلی چیست
- بدون گم شدن، از خانه تا PDF برسیم
- اکشن اصلی هر صفحه فقط یکی باشد (CTA واضح)

### ۴.۳ تطابق با برند اسمارت

- پالت olive/lime بالا را حفظ کن
- کامپوننت‌ها شبیه Club/Desk/Backoffice اسمارت (DS)، نه قالب عمومی
- تصاویر تزئینی بی‌ربط نگذار؛ اگر ویژوال لازم است، محصول/گزارش/کیفیت را نشان بده
- RTL را جدی بگیر (آیکون جهت، چیدمان سایدبار راست، متن راست‌چین)
